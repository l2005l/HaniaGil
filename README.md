# hania גיל

מחשבון גיל מדויק לפי תאריך לידה לועזי או עברי, עם רשימות משפחה וחברים ותזכורות לימי הולדת.
אפליקציית רשת (PWA) שאפשר להתקין למסך הבית ועובדת גם בלי אינטרנט.

**כתובת:** https://gil.hania360.com

## קבצים
- `index.html` – האפליקציה
- `cal.js` – חישובי לוח עברי ולועזי, ימי הולדת ותזכורות
- `sw.js` – עבודה בלי אינטרנט ובדיקת תזכורות ברקע
- `manifest.webmanifest`, `icons/` – התקנה כאפליקציה
- `CNAME` – הדומיין gil.hania360.com עבור GitHub Pages

## עדכון גרסה
אחרי שינוי בקבצים, להעלות את המספר ב־`VERSION` שבקובץ `sw.js` (למשל `hania-gil-v2`), כדי שהטלפונים יקבלו את הגרסה החדשה.

## פרטיות
הרשימות נשמרות במכשיר של המשתמש (localStorage). אין שרת ואין איסוף נתונים.

לא חובה: מי שמחובר לחשבון Hania360 יכול לבחור "שמירה בחשבון" בהגדרות. אז הרשימות נשמרות גם בחשבון (pass.hania360.com), עוברות לטלפון אחר אחרי כניסה, וימי הולדת קרובים מופיעים ב־Hania Today. "הפסקת השמירה בחשבון" מוחקת אותן מהחשבון.
